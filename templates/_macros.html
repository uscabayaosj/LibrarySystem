{# Shared render macros. Keeping these in one place is what stops two screens from drifting apart -- the borrower dashboard and My Loans previously mapped the same due_state to different badge colors (a healthy loan read green on one screen, blue on the other). One macro, one mapping, every surface. #} {% from "_icons.html" import icon %} {# The single due-state -> badge mapping. Color tracks urgency and nothing else: red = overdue, orange = due today/soon, blue = on loan with time to spare, green = returned (positive closure). Green is reserved for the done state so it never also means "healthy active loan" -- that ambiguity was the cross-screen inconsistency. #} {% macro due_badge(b) -%} {%- if b.status == 'returned' -%} {{ icon('check', class='icon-sm') }} Returned {%- elif b.due_state == 'overdue' -%} {{ b.due_label }} {%- elif b.due_state in ['today', 'soon'] -%} {{ b.due_label }} {%- else -%} {{ b.due_label }} {%- endif -%} {%- endmacro %} {# A sortable column header. One macro for all three admin tables, for the same reason due_badge exists: three hand-rolled versions is how they drift. Renders a real link, not a JS handler, so the sort is bookmarkable, survives a reload, and works with the keyboard for free. aria-sort is what tells a screen-reader user which column the table is ordered by -- the caret alone says it only to people who can see it. `params` carries the rest of the querystring (search, filter, and so on) so sorting never silently drops the view the librarian had set up. Clicking the active column flips direction; clicking a new one starts ascending, which is what every table in every OS does. #} {% macro sort_th(label, key, endpoint, sort_key, sort_dir, params={}, numeric=false) -%} {%- set is_active = (sort_key == key) -%} {%- set next_dir = 'desc' if (is_active and sort_dir == 'asc') else ('asc' if is_active else 'asc') -%} {{ label }} {%- if is_active -%}{{ '↑' if sort_dir == 'asc' else '↓' }}{%- else -%}↕{%- endif -%} {%- if is_active %}, sorted {{ 'ascending' if sort_dir == 'asc' else 'descending' }}, click to reverse {%- else %}, click to sort{% endif -%} {%- endmacro %}
